PROJECT 01

Designing Fiber Optic Networks Using Google Earth Pro

This project involves designing a fiber-optic network using Google Earth Pro to support the planning and visualization of FTTH (Fiber to the Home) infrastructure.

About Project

The project involved mapping potential fiber routes, identifying locations of ODP, ODC, and customer premises, and estimating cable distances based on geographic conditions.

This approach helped create a more accurate and efficient network design while providing a clear visual representation of the planned fiber optic infrastructure.

Tools & Technologies

Google Earth Pro Google Maps / Google Earth Street View PC/Laptop Measurement & Path Tools KML/KMZ

Designing Fiber Optic Networks Using Google Earth

Testing

Testing of the network topology design was conducted using Google Earth Pro to ensure that network paths and points align with the site's geographical conditions.

  • ✓ Fiber optic paths correspond to locations on the map
  • ✓ Network points are accurately positioned
  • ✓ Distances between network points can be measured
  • ✓ Network routes can be clearly visualized
